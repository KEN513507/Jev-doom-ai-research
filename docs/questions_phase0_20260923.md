## D3: スコア式に EXIT と全滅を入れるか

推奨：入れる。自動ループの改善判断がこのスコアで行われるため。

- 現行 full_map：kills×500 ＋ visited×10 − hits×100 ＋ health
- 追加案：I_EXIT ボーナス、全滅（full_clears）ボーナス

質問：入れるか。入れる場合、EXIT と全滅の係数はいくらにするか（例：EXIT=10000 は SSOT §3 の Clear Score と一致）。
＞＞アンサー：既存の配点（Kills=500, Hits=-100）のスケール感、および SSOT §3（Clear Score = 10000） との整合性を担保するため、以下の係数を推奨します。 ボーナス名推奨係数期待されるAIの挙動変化EXITボーナス+10,000ゴール（クリア）を明確な「最優先目標」と認識させ、遅延ループを防止します。全滅ボーナス+5,000「敵を1体だけ残して即ゴールする」ような手抜きを抑止し、マップ探索と戦闘のインセンティブを両立させます。新・スコア計算式（案） \[\text{Score}=(\text{kills}\times 500)+(\text{visited}\times 10)-(\text{hits}\times 100)+\text{health}+(\text{EXIT}\times 10000)+(\text{full\_clears}\times 5000)\]

＞＞訂正（2026-09-23）：EXIT・全滅ボーナスは他の項と同じくエピソード平均に掛ける（`avg_i_exit × 10000` + `(full_clears / n) × 5000`）。SSOT §3 の Clear Score（1エピソード単位）と一致させるため。
