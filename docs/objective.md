# 研究目的

## 主目的
- **Jev（TypeSafe AI）の判断プロセスの可視化**
- **criteria変更が判断に与える影響の定量化**
- **リアルタイム環境でのLLMエージェントの限界と可能性**

## 評価指標
| 指標 | 定義 | 目標 |
|------|------|------|
| avg_hits | 平均被弾回数 | 最小化（現実的上限 ≤ 2.0） |
| avg_health | 最終HP平均 | 最大化 |
| avg_steps | 生存ステップ数 | バランス（150〜250付近） |
| sys2_ratio | Jev判断率 | 50〜90% |
| kills | 撃破数 | 最大化 |

## 制約
- **リアルタイム維持**（frame_skip は下げない。現行4）
- **Git操作は人間のみ**（AIはcommit/push禁止）
- **APIキーは環境変数**（`TYPESAFE_API_KEY`）
- **ウィンドウ表示必須**（`set_window_visible(True)`）

## 成功条件
- Jevが敵を撃破（✅ 達成：tactical_p2でkills=2）
- criteria変更で行動が変化（✅ 達成：Finding 2）
- 自動イテレーションループの確立（✅ 達成：Finding 8）

## 物理的制約（受容済み）

- 被弾ゼロはクラウドJevでは非現実的。「hits ≤ 2.0」が現実的上限
